# Project Memory

## Project
- Static portfolio site for Lucian Rodríguez Plasencia based on `Curriculum Lucian_1.pdf`.
- No existing web framework, package manager, or UI component system was present.
- Main entry point is `index.html`; styles and browser interactions live in `styles.css` and `script.js`.

## Design and implementation
- Spanish-language editorial portfolio with warm paper, dark green, and rust solid-color tokens; Georgia display type and system sans-serif body.
- Responsive layouts use a single CSS file and fluid sizing; no gradients, external fonts, icon packs, or runtime dependencies.
- Hero parallax uses requestAnimationFrame and a small CSS transform; reveal effects use IntersectionObserver. Both respect `prefers-reduced-motion`.
- Mobile navigation is a native disclosure button with `aria-expanded`, Escape-to-close, and link activation to close.
- A scroll-driven ink-reveal interlude lives between the portfolio hero and recognition strip. It uses a locally authored SVG night-town illustration, a custom Canvas 2D procedural ink edge on desktop, and CSS circular layers on coarse-pointer phones. The red overlay and title appear together at the end of the reveal, and the final solid-red state remains visible through the end of the scroll section. The replay control and its scroll handler were removed.
- Ink scene geometry is read from its in-page journey marker after image decoding and font readiness; no global fixed-scroll runtime or external assets are added.
- Search metadata includes Spanish description/title, Open Graph and Twitter summary fields, and Person JSON-LD. The single decorative workflow SVG remains vector, lazy-loaded, asynchronously decoded, and low priority; no raster conversion or render-loop changes were justified by its 4.1 KB size and existing requestAnimationFrame scheduling.
- A read-only security review found no exploitable vulnerabilities in the static site. Cloudflare Pages response headers are configured in `_headers`; they remain unverified on the live host until deployment. Canonical URL, sitemap, and absolute social-preview image metadata need the final public domain.
- Cloudflare Pages deployment uses `node build.mjs` with `dist` as the output directory. The allowlisted build excludes graph and workspace files, applies `_headers`, and generates canonical/OG URL metadata plus sitemap directives when an HTTPS `SITE_URL` is configured; without it, no placeholder domain is published. Security headers include CSP, HSTS, clickjacking/MIME/referrer protections, and least-privilege browser permissions; CSP allows inline styles because scroll effects update CSS properties at runtime. LinkedIn profile metadata uses the user-provided URL.
- Resume facts are sourced from the included two-page PDF. Use the PDF as the source of truth when updating career content.

## Accessibility and verification notes
- Semantic landmarks, skip link, visible keyboard focus, descriptive link text, touch-sized navigation controls, and responsive reflow are included.
- Verified in a browser at desktop and 320px widths: no horizontal overflow, internal anchors resolve, the mobile menu opens/closes by click and Escape, and the parallax runs without console errors.
- Verified reduced-motion mode disables parallax and makes reveal content visible. Key text color pairs measure at least 4.7:1 after contrast adjustments.
- Verified the ink scene in Chrome at 1440x900: inactive, expanding, filled, final red/title state, and reverse-scroll states; the background decodes before readiness.
- Verified coarse-pointer fallback at 390x844 and 320x740 with the native phone predicate, CSS ink layers, and no horizontal overflow. Reduced-motion mode remains a static red scene with the title visible.
- Verified resize redraw at 1280x720 without application-driven scroll reset, simulated canvas context loss switches to the CSS fallback, and `pagehide` clears the canvas and removes the viewport probe.
- Verified SEO metadata and JSON-LD parse in-browser, one H1, unique IDs, working in-page anchors, lazy/async/low-priority SVG attributes, and no editor diagnostics or JavaScript syntax errors. Repository assets remain small (HTML ~22 KB, CSS ~29 KB, scripts ~17 KB, SVG ~4 KB); no Lighthouse run or production-host response-header check was performed.
- The allowlist build was run locally with and without a sample HTTPS `SITE_URL`; canonical/OG URL, robots/sitemap, and exclusion of workspace files passed. Configure `SITE_URL` with the final `https://<project>.pages.dev` or custom origin before publication. Cloudflare response headers have not been verified on a live deployment, and no Lighthouse run was performed.
- Latest browser console had no errors or warnings; observed requests were local HTML, CSS, JS, and SVG only.
- Physical-device touch, landscape rotation (emulator reported landscape while page metrics remained portrait), hidden-tab pause, and assistive-technology testing were not verified. No Lighthouse or full WCAG audit was run; do not claim formal conformance.
